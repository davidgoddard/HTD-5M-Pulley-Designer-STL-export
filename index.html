STL pulley designer

5M 15 mm timing pulley generator

Static browser tool for designing printable 5 mm pitch timing pulleys. Set the tooth count, bore, face width, flanges, and arc-based HTD groove dimensions, then export an ASCII STL file.

Pulley size and tooth profile

Pitch fit calibration

If one belt tooth seats but teeth several pitches away do not, that is accumulated pitch error. For a 5-tooth check, every 0.01 mm change in Effective pitch moves the fifth tooth by 0.05 mm. Start with 5.00 mm, then try 5.02, 5.04, or 4.98 depending on whether the pulley grooves are too close together or too far apart.

Flanges and bosses

Lower and upper flanges can be switched independently. Square flanges give the cleanest pulley shape; the optional upper taper is only for support-free FDM printing.

Manufacturing note

This app generates the groove from tangential arc geometry using OD offset, groove depth, plunge radius, floor/corner radius, explicit pulley tooth crest width, and printable mid-groove side relief. If one belt tooth seats but teeth 4–5 pitches away do not, tune Effective pitch / tooth spacing first; OD offset and flank relief will not fix accumulated pitch drift. It is still not a certified manufacturer profile unless those dimensions match the exact belt maker's published data and tolerances.
